# Security Policy

Security issues affecting OduwaCoin Core should be reported responsibly.

## Supported release

The current public release line is:

| Version | Supported |
| --- | --- |
| 2.0.0.2 | Yes |
| Earlier releases | Upgrade recommended |

Security fixes may require users, node operators, staking operators, exchanges, and other infrastructure providers to upgrade promptly.

## Reporting a vulnerability

**Do not publish exploit details, private keys, wallet files, credentials, or other sensitive material in a public GitHub issue.**

When GitHub private vulnerability reporting is available for this repository, use the repository's **Security** tab to submit a private report to the maintainers.

If private reporting is not available, open a minimal public issue requesting a private maintainer contact channel. Do not include exploit instructions or sensitive details in that issue.

A useful security report should include:

- the affected OduwaCoin Core version
- affected operating system or build environment
- a concise description of the issue
- reproduction conditions, where safe to provide privately
- expected security impact
- any proposed patch or mitigation
- whether the issue is already known or publicly disclosed elsewhere

## Coordinated disclosure

Please allow maintainers reasonable time to reproduce, assess, patch, test, and prepare upgrade guidance before public disclosure.

Consensus, networking, wallet, RPC, staking, cryptographic, and private-key handling issues should be treated as potentially security-sensitive until reviewed.
